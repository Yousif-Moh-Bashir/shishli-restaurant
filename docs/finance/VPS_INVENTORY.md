# تقرير محاولة جرد VPS للقراءة فقط

تاريخ العمل: 2 نوفمبر 2026. الإذن: فحص Git والحاويات والخدمات والمنافذ والوكيل والشهادات والمساحة دون تعديل الخادم أو قراءة قاعدة الإنتاج/سجلات العملاء.

**النتيجة: الجرد متوقف قبل الاتصال؛ لا توجد نتائج موثقة من الإنتاج.**

## العائق وما نُفذ

- روجعت خطة STAGED_DEPLOYMENT وإعدادات Compose المحلية ومصدر المصادقة والـwebhooks ذات الصلة.
- البحث المحلي في وثائق النشر لم يثبت عنوان SSH وحساب الدخول ومسار checkout الفعلي؛ الوثائق تستخدم مسارات REPLACE وتصف تحققًا محليًا.
- محاولة سرد أسماء ملفات مجلد إعدادات SSH المحلي `%USERPROFILE%\.ssh` أعادت `UnauthorizedAccessException / Access is denied`. لم تُقرأ مفاتيح خاصة أو قيمها ولم يصل التنفيذ إلى اتصال SSH.
- التزامًا بطلب المستخدم، لم تُطلب ترقية صلاحية، ولم يُستخدم بديل لتجاوز المنع، ولم تُغيّر ACL أو العضوية أو إعدادات known_hosts. لم يُجرَّب اسم مستخدم/عنوان IP بالتخمين.
- لم تنفذ أوامر على VPS، ولم يُنشأ ملف جرد هناك، ولم تُقرأ SQL أو سجلات العملاء. لا restart/pull/reset/checkout/DNS/TLS/migrations/seeders أو نسخ إنتاج.

## تحديثات خطة الأمان في هذه الجولة

1. نسخ SQL/Storage مشفر أثناء البث، وتحديد Storage volume قبل توقف app وتركيبه read-only مباشرة دون exec داخل حاوية متوقفة. إزالة مؤقتات مسماة فقط بعد توثيق الاستعادة الخارجية، مع حدود المحو على SSD/CoW.
2. فصل اختبارات HTTPS الخارجية403/503 عن API المصرح بها داخليًا401 دون توكن.
3. إضافة ROLLBACK_REHEARSAL لصور Laravel القديمة/الجديدة وfinance.* والتوكنات والحساب المشترك. خطوات جاهزة، **لم ينفذ التمرين**؛ صورة الإنتاج السابقة لم تثبت.
4. قياس metadata لخدمات البيانات قبل كل تبديل وبعده، مع خدمة مسماة و--no-deps ومنع up العام؛ **لم يثبت تجريبيًا على VPS**.
5. بوابة صيانة503 صريحة، تصريف الأعمال، شرط تأكد retry/replay عند مزود الدفع، ومصالحة كل تأكيد طلب/مرجع دفع. لا ادعاء بضمان عدم الفقد قبل تنفيذ ذلك بإذن لاحق.

## نقطة التوقف

التحقق المحلي لهذه التعديلات: نجح `bash -n` لـ19 مقطع Bash في خطة النشر و4 مقاطع في تمرين التراجع، ونجح اختبار منع تتبع الجلسات/ملفات البيئة1/1، ونجح `git diff --check`. هذه فحوص صياغة/مستودع وليست تنفيذ نسخ أو استعادة أو تراجع. الملفات المتغيرة في هذه الجولة هي STAGED_DEPLOYMENT.md وROLLBACK_REHEARSAL.md وهذا التقرير فقط؛ لم تُعدل ملفات التطبيق أو Docker التشغيلية.

يُنتظر توجيه جديد لمعالجة عائق الوصول وفق سياسة المستخدم، أو تزويد قناة SSH المصرح بها ونتائج جرد من مشغل مخول. لا تُرسل مفاتيح أو كلمات مرور في المحادثة. لا يُستأنف تجاوز الصلاحيات تلقائيًا، ولا يبدأ النشر. ما زال إذن DB والنسخ وDNS/TLS وتغيير الخدمات مطلوبًا بصورة منفصلة مهما كانت نتيجة الجرد اللاحق.
