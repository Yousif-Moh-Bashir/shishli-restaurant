# Release blockers

تحديث 2026-10-12: اكتملت بيئة Docker المحلية والتحقق من المرحلة الثانية. حالة المحرك والحاويات الحالية ونتائج الاختبارات والاستعادة في [تقرير المرحلة الثانية](../docker/PHASE_2_REPORT.md). فقرات Docker أدناه تسجل حالة تدقيق 2026-10-11 التاريخية؛ تبقى متطلبات بيانات التشغيل وHTTPS والمضيف الفعلي قبل استقبال العملاء.

2026-10-11. يميز هذا التقرير إطلاق استقبال العملاء عن الانتقال إلى تجهيز Docker. الميزات الاختيارية لا تمنع الإطلاق النقدي تلقائيًا.

## P0 — يمنع الإطلاق

لا يوجد مانع برمجي P0 مفتوح ومثبت في مسار cash المحلي بعد الإصلاحات. لم تُثبت سلامة إنتاج حقيقي، لذلك هذا ليس تصريح إطلاق. إذا نُشرت نسخة debug/development، أو أسرار/حسابات demo، أو اختبارات مرتبطة بقاعدة المطعم، فهي مانع إطلاق حتى التصحيح؛ لم ينشر التدقيق أيًا منها.

## P1 — قبل استقبال العملاء

| العنصر | الوضع الحالي | معيار الإغلاق |
|---|---|---|
| بيئة نشر production/HTTPS/أسرار/DB مستخدم مخصص | NOT VERIFIED؛ الإعداد المحلي ليس إنتاجًا | staging production مع debug=false وHTTPS وAPP_KEY صحيح وإعدادات DB آمنة |
| CORS وطوبولوجيا الوكيل | إصلاح الكود محليًا مكتمل؛ إعداد البيئة الفعلي معلق | allowlist حسب الدومين وproxy IP/CIDR الحقيقي؛ تحقق HTTPS وclient IP وعدم تزويرهما |
| تجهيز بيانات المطعم وأول admin وحسابات التشغيل | NOT VERIFIED؛ production seed لا ينشئ admin | بيانات معتمدة وحساب أول إدارة آمن؛ لا demo/كلمات مرور معروفة في قاعدة الإصدار |
| توفر القائمة والساعات ورسوم التوصيل وسياسات التحصيل | البرمجيات مختبرة، الاعتماد البشري معلق | إكمال [قائمة التشغيل](OPERATIONAL_READINESS.md) وتجربة حالات الفشل |
| شبكة لطلبات التوصيل | تحصيل المندوب cash فقط؛ terminal غير مختبر | إجراء جهاز/تحصيل كاشير واضح قبل delivered أو حسم استبعاد شبكة من نطاق الإطلاق |
| تطابق محرك قاعدة النشر مع الاختبارات | MariaDB 10.4.25 مختبر؛ Oracle MySQL NOT VERIFIED | الاختبارات/الترحيلات على إصدار قاعدة الحاويات المعتمد |
| Backup/restore/rollback وstorage/permissions/مراقبة التطبيق | لم يُختبر VPS أو containers | تجربة استعادة قاعدة+uploads وإعادة إصدار، وفحص صلاحيات uploads وhealth/logs |
| رحلة الطلب على staging بعد Docker | اختُبرت محليًا؛ staging غير موجود | cash → مطبخ → مندوب → تحصيل وتسوية وتقارير عبر reverse proxy الفعلي |

Docker Engine **غير شغال** في البيئة الحالية. هذا عائق بيئي لتشغيل/اختبار حاويات المرحلة الثانية، لا عيب في رحلة الطلب. يمكن إعداد ملفات Docker، لكن يجب تشغيل المحرك لإثبات عملها. لم يغير التدقيق إعدادات Docker أو يشغله تلقائيًا.

## مشكلات أُغلقت في هذه المرحلة

| المشكلة | الإغلاق |
|---|---|
| production CORS يعتمد wildcard ولا allowlist | `config/cors.php` وCORS_ALLOWED_ORIGINS مع اختبارات |
| Retry-After غير متاح لواجهة cross-origin | expose Retry-After/Request-ID واختبار استجابة 429 |
| غياب خيار trusted proxy في إعدادات المشروع | config/trustedproxy.php دون ثقة عامة؛ اختبار scheme/IP |
| افتراض ترقيم SH-0001 في كل اختبار على MySQL | اختبار صيغة وتميز وحفظ الرقم؛ 202 حالة MariaDB تمر |

## P2 — تحسين مهم يمكن جدولته

- تجربة الأداء بحجم بيانات واقعي وعلى هواتف وشبكة الإنتاج، وإعادة التحقق من LCP/CLS/INP الفعلي. نتائج localhost ليست SLA.
- PHP-FPM/OPcache وضغط HTTP وكاش hashed assets في المرحلة الثانية؛ لا تبنِ الخدمة حول Vite dev أو PHP CLI single worker.
- سياسة عمر PAT وتدوير/إبطال التوكنات، ومراجعة CSP مع تخزين التوكنات في localStorage.
- مراقبة queue/backoff/deduplication إذا فُعل إرسال خارجي؛ الإرسال الحالي معطل عمدًا.
- مزود دفع حقيقي وإرسال OTP/SMS/WhatsApp/email واستعادة كلمة المرور: تحتاج تنفيذًا وتكاملًا وتجارب مستقلة. تصبح P1 فقط إذا دخلت ضمن نطاق الإطلاق المعلن.
- عزل عام لموظفي الإدارة حسب الفرع إذا تطلبت سياسة التشغيل ذلك؛ يصبح P1 لإطلاق متعدد الفروع يشترط هذا العزل.
- إقرار seeding انتقائي لا يعيد قيم branch/catalog المخصصة. لا تشغل default seeder على قاعدة قائمة دون مراجعة أثره.
- مراجعة الأجهزة والمتصفحات الحقيقية ورفض/تعطل إذن الموقع؛ اختبارات Chrome والمنطق لا تشمل Safari/iOS بالكامل.

## P3 — تحسين لاحق

- أحجام صور responsive/srcset وAVIF عند توفر قياسات وصور فعلية؛ WebP الحالي موجود بالفعل.
- استضافة خط Tajawal محليًا إذا أثبت القياس أن الاتصال الخارجي سبب تأخير.
- GPS حي للمندوب ووظائف إضافية غير لازمة لتشغيل الطلب النقدي الحالي.

النتيجة: **GO لتجهيز Docker مشروطًا بتشغيل المحرك والتحقق من بيئة الحاويات؛ NO-GO لاستقبال العملاء قبل إغلاق P1.**
