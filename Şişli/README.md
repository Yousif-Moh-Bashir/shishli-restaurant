# مطعم شيشلي — الصفحة الرئيسية

## إضافة العروض

عدّل `window.Shishli.offers` في `assets/js/data.js` ثم أعد تحميل الصفحة. مثال:

```js
window.Shishli.offers = [
  { productId: 4, title: 'عرض الشيش', price: 16, active: true }
];
```

يظهر قسم العروض في الرئيسية والمنيو عند وجود عرض مفعّل بسعر أقل من السعر الأصلي. يستخدم `productId` رقم منتج موجود في الكتالوج. سعر العرض يطبق أيضًا في بطاقات المنتجات والسلة والإجمالي. لتعطيل عرض ضع `active: false`؛ ولإخفاء القسم بالكامل اجعل القائمة `[]`. المثال غير مفعّل افتراضيًا. هذه إعدادات ملفات للواجهة الحالية، وليست لوحة إدارة.

واجهة عربية RTL باستخدام HTML وCSS وVanilla JavaScript. افتح `index.html` مباشرة، أو عبر خادم XAMPP. لا تحتاج إلى تثبيت حزم أو تشغيل عملية بناء.

صفحة `menu.html` تعرض كتالوج المنتجات مع التصنيفات والبحث والترتيب حسب السعر والإضافة للسلة. السلة مشتركة مع الصفحة الرئيسية عند فتح الصفحتين من نفس الموقع. بقية الصفحات الفارغة لم تتغير.

## الصور والبيانات

- الصور مؤقتة من التصميم المرجعي المرفق. تُعرض مناطق الصور بواسطة CSS دون تعديل الأصل. صورة الواجهة توضيحية وليست توثيقًا لفرع حقيقي.
- لاستبدال صور المنتجات، أضف ملفات إلى `assets/images/products/` واضبط خاصية `image` لكل منتج في `data.js` على مساره النسبي. الخاصية `photo` تُستخدم للصور المرجعية فقط.
- صور الـHero والواجهة والشعار تُحدد في `.hero-art` و`.about-photo` و`.brand-image`. عند وضع صور مستقلة، استخدم `background-size: cover` و`background-position: center` (و`contain` للشعار).
- الأسعار أمثلة من الطلب، وساعات العمل توضيحية تحتاج اعتماد المطعم. لم تُخترع روابط حسابات التواصل؛ تعرض الأزرار غير المزوّدة بروابط رسالة واضحة.
- خط Tajawal يُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط بديلة محلية. الصور والأيقونات والوظائف الأساسية محلية.

## السلة

سلة تجريبية مع إضافة، وتعديل كمية، وحذف، وإجمالي، وحفظ محلي بالمفتاح `shishli.cart.v1`. لا ترسل طلبات ولا تجمع معلومات حسابات أو مدفوعات. إذا تعذر التخزين، تعمل السلة للجلسة الحالية ويظهر تنبيه.

بيانات المنتجات مستقلة في `data.js`. تحميل/حفظ السلة معزولان في كائن `storage` داخل `main.js` لتسهيل الربط لاحقًا بـAPI. يُعاد حساب السعر من الكتالوج ولا يُوثق سعر من التخزين المحلي. الـHeader والـFooter لهما تنسيقات مستقلة لإعادة استخدامهما مستقبلاً.

مسارات الأيقونات مبنية على Lucide، بترخيص ISC. انظر `assets/icons-LICENSE.txt`.
