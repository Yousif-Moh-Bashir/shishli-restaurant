# لوحة تحكم شيشلي

حقول المنتجات تشمل الصورة والوصف والمكونات والوزن بالجرام والسعرات لكل حصة ومسببات الحساسية. يمكن رفع PNG/JPG/WebP حتى 1 ميجابايت أو إدخال رابط صورة. الصور المرفوعة تحفظ محليًا ضمن بيانات اللوحة (وقد تمتلئ مساحة المتصفح عند إضافة صور كثيرة). القيم الغذائية اختيارية ولا يتم اختلاق قيم للمنتجات القديمة؛ تُضاف الحقول دون مسح البيانات الموجودة. لا تنتقل هذه التفاصيل إلى واجهة المطعم قبل ربط النظامين.

افتح `index.html` داخل هذا المجلد. جميع صفحات اللوحة وملفات CSS وJavaScript وصورة الشعار مستقلة داخل `dashboard/`، ولا تعتمد على ملفات واجهة المطعم.

```text
dashboard/
  index.html        إحصائيات محسوبة من البيانات وآخر الطلبات
  orders.html       البحث والتصفية وتفاصيل الطلب وتحديث حالته
  products.html     إضافة وتعديل وحذف المنتجات والأسعار والتوفر
  categories.html   إدارة التصنيفات وربط المنتجات بها
  offers.html       إضافة وتعديل وحذف العروض وحالة تفعيلها
  customers.html    العملاء وسجل طلباتهم
  settings.html     بيانات المطعم والخريطة وأوقات العمل
  assets/
    css/dashboard.css
    js/store.js
    js/dashboard.js
    images/logo.png
```

اللوحة Front-End فقط ببيانات تجريبية معلّمة بوضوح. التخزين المحلي منفصل بالمفتاح `shishli.dashboard.v1`. لا تقرأ سلة العملاء ولا تعدّل ملفات المتجر أو عروضه. لا توجد مصادقة مدير أو قاعدة بيانات أو إرسال طلبات. لا تُعتبر هذه الواجهة نظام إدارة محميًا للإنتاج؛ الحماية والتحقق من الصلاحيات والربط بالمتجر تحتاج خادمًا في مرحلة لاحقة.

`store.js` يعزل التخزين والبيانات التجريبية لتسهيل استبداله لاحقًا بـ API. فشل الحفظ يعرض رسالة ولا يعتبر التغييرات محفوظة. حذف منتج يحذف عروضه المرتبطة ويحتفظ بنسخة بياناته التاريخية داخل الطلبات. الإحصائيات محسوبة من نفس بيانات الطلبات، ولا تعرض مدفوعات أو أرقامًا حقيقية.

التصنيفات الحالية تُستخرج من المنتجات القديمة تلقائيًا دون مسح البيانات. يدعم القسم الإضافة والتعديل والبحث والحذف مع عدد المنتجات. تعديل اسم التصنيف يحدث تصنيف منتجاته، ويُمنع تكرار الاسم أو حذف تصنيف مرتبط بمنتجات. اختيار تصنيف المنتج يتم من قائمة التصنيفات المحفوظة.
