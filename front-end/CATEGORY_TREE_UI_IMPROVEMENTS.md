# تحسين شجرة التصنيفات

استُبدلت القائمة النصية المسطحة بشجرة متداخلة تحفظ علاقات الخادم. مستويات واضحة وخطوط اتصال، فتح وطي كل فرع أو جميع الفروع، وبحث يحفظ مسار الأقسام الرئيسية إلى النتيجة. حالة التفعيل وإجراءات التعديل والحذف حسب صلاحيات المستخدم، مع تعطيل الإجراءات أثناء الطلب. تبقى نافذة التعديل وتأكيد الحذف الحالية مسؤولة عن الحفظ والتحقق والأخطاء.

## BACKEND → FRONTEND COVERAGE

- الخادم يوفر GET /admin/categories/tree مع children وis_active والترتيب والأسماء؛ ويوفر القراءة والإنشاء والتعديل والحذف بصلاحيات categories.view/create/update/delete.
- الشجرة القديمة سطّحت العلاقات إلى نصوص؛ حافظت خيارات التصنيف في المنتجات على قائمة مسطحة، بينما أصبح عرض الشجرة يستخدم العلاقات الأصلية.
- أُضيف البحث المحلي والطي والتوسيع وإجراءات الصفوف وحالات التحميل والخطأ وإعادة المحاولة والفراغ. عند إعادة الحفظ تُحمّل الشجرة من الخادم كالمعتاد.
- لا يُختلق عدد منتجات عند غيابه من المورد؛ يظهر فقط حين يرسله الخادم. لا تُعرض المعرفات كحقول للمستخدم، ولا تُضاف عمليات نقل بالسحب أو إعادة ترتيب غير مدعومة بالعقد الحالي.

التحقق: بناء الإنتاج واختبار المكون في Chrome بمستويات متداخلة، والبحث ومسار النتيجة والطي والتوسيع والصلاحيات والأحداث والفراغ والتجاوب عند 390 و768 و1440. الاختبار معزول، ولا يعدل تصنيفات المطعم فعليًا.
