# تحسين إضافة صور المنتج

منطقة لاختيار الصور أو سحبها، وتوضيح الصيغ وحدود الحجم والعدد. معاينات تحتوي اسم الملف وحجمه وإزالة صورة من الاختيار أو مسح الاختيار بالكامل، مع تمييز الصورة الرئيسية قبل الحفظ. زر الرفع يبقى باللون #d71920 وتظهر حالة الرفع بوضوح.

## BACKEND → FRONTEND COVERAGE

- حافظ التعديل على productImagesApi ورفع multipart وimages[] وalt_text وis_primary، والصلاحية products.update، وأخطاء Laravel422 وتحديث الصور بعد نجاح الخادم.
- حدود StoreProductImageRequest: حتى 10 صور للطلب، 5 ميجابايت لكل صورة، JPG/PNG/WebP؛ وتبقى حدود المنتج الحالية معروضة.
- أضيف السحب والمعاينة وإزالة الملفات غير المحفوظة والعداد والحجم والتسمية الرئيسية. هذه إدارة للاختيار قبل الرفع؛ لا تُحذف صور محفوظة دون إجراء الحذف والتأكيد القائمين.
- الخادم يتحقق من محتوى الصورة والحفظ والترتيب والرئيسية؛ لا تُستبدل هذه القواعد بمعاينة محلية ولا تُعرض المعاينة كصورة محفوظة.

التحقق: نجح npm run build. لم يُجرَ رفع فعلي لصور إلى بيانات المطعم في هذه الجولة.
