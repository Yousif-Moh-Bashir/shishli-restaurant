# تحسين السلة

أُعيد ترتيب صفحة السلة إلى قائمة منتجات وملخص مستقل، مع ترتيب عمودي على الهاتف. صُغرت الصور وأدوات الكمية، وأُبرز الإجمالي والمتابعة، وجُمعت أدوات التحديث والإفراغ. التحسينات المشتركة تشمل نافذة السلة أيضًا، وتستخدم ألوان الموقع وخط Tajawal وRTL. موضع الصورة المفقودة محايد، دون اختلاق صور منتجات.

حُسّن ملخص الطلب بعنوان وأيقونة وعدد القطع، ومساحة منفصلة للإجمالي مع توضيح استثناء التوصيل، وحقل كوبون قابل للفتح يظهر مفتوحًا عند وجود كوبون مطبق. زر إكمال الطلب #d71920، ورابط إضافة الأطباق أخف بصريًا. أُبقي الإجمالي والخصم من استجابة السلة دون إعادة حساب محلية. نجح بناء الإنتاج بعد هذا التعديل.
