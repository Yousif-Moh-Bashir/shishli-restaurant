# تحسين المنيو

بحث واختيار فرع في منطقة واحدة، تصنيفات قابلة للسحب، فلاتر التوفر والتمييز، مسح جميع الفلاتر، عنوان نتائج واضح، وعدّاد للسلة. بطاقات أخف بأربعة أعمدة على الكمبيوتر وعمودين على الهاتف؛ جميع التنسيقات الجديدة محصورة في صفحة المنيو. حافظت الصفحة على هوية شيشلي وTajawal وRTL.

## BACKEND → FRONTEND COVERAGE

- MenuController وMenuRequest وMenuService يدعمون branch وsearch وcategory وfeatured وavailable، مع أسعار الفرع والتوفر والمخزون والترتيب والصور.
- الواجهة الحالية تغطي هذه العقود وخيارات المنتج عبر صفحة التفاصيل والإضافة للسلة؛ لم تتغير APIs أو المخازن أو قواعد الأسعار.
- النواقص المعالجة: فصل أدوات التصفح عن نتائج الأطباق، وضوح البحث والتصفية، مسح الفلاتر معًا، استعادة النتائج الفارغة، إبراز مراجعة السلة وتحسين بطاقات الهاتف.
- إعدادات المخزون وتعيين المنتجات للفروع وإدارة الصور تبقى في الإدارة؛ لا تُعرض كحقول للعميل. لا يوجد فرز مخترع أو كتالوج تجريبي بديل.

التحقق: بناء الإنتاج وفحص المتصفح بأحجام 390 و768 و1440، مع استجابات نقل معزولة للبحث والتصنيفات والأسعار والتوفر والفراغ والخطأ وإعادة المحاولة. لا ينشئ الاختبار مشتريات أو يغير بيانات المطعم. صور المنتجات غير المضافة في الخادم تبقى مواضع محايدة.
