# فحص الإعدادات والتشغيل

التاريخ: 2026-10-05. اختُبرت الواجهة فعليًا في Chromium مع Laravel المحلي، دون حفظ تغييرات تشغيلية.

اختُبرت التابات الثمانية: بيانات المطعم، التواصل، الهوية، استقبال الطلبات، الاستلام، التوصيل، تشغيل الفروع، سجل التغييرات. جرى التنقل بينها على عروض 1440 و1024 و768 و390 و360 و320 بكسل: 48 حالة. أضيفت فترة عمل كمسودة ثم جرى التراجع عنها، وفُتحت وأُغلقت نافذة الإغلاق المؤقت على الأحجام الستة: 12 حالة إضافية.

النتيجة: لا تمرير أفقي للصفحة، ولا تقاطع بين عناصر شبكات التخطيط المفحوصة، ولا خروج للمودال من حدود الشاشة أو overflow أفقي فيه. لا أخطاء أو تحذيرات JavaScript سجلها الاختبار. روجعت صور بيانات المطعم واستقبال الطلبات وتشغيل الفروع والمودال بصريًا؛ نتائج بقية التابات محفوظة آليًا مع صورها.

لم يثبت الفحص الحالي وجود تداخل يتطلب تعديل CSS. لم يُغيّر التصميم أو إعدادات الخادم. هذا فحص لبيئة Chromium المحلية وهذه الحالات؛ لا يستبعد مشكلة مرتبطة بمتصفح آخر أو بيانات/zoom مختلفين.

## BACKEND → FRONTEND COVERAGE

يغطي الفحص واجهات الإعدادات وحقول المجموعات الفعلية، حالة الفرع وخيارات تشغيله، جدول الأسبوع، الإغلاقات المؤقتة وسجل تغييرات الإعدادات. لا تغيير في APIs أو صلاحياتها. لم تُكتشف وظيفة واجهة ناقصة ضمن نطاق فحص التابات. حساب الحالة التشغيلية وحفظ الإعدادات وسجلها يبقيان في Laravel؛ هذا الاختبار لم يرسل طلبات حفظ تشغيلية.

الاختبار القابل لإعادة التشغيل: [settings-tabs.browser.mjs](../tests/settings-tabs.browser.mjs). الصور ونتائج القياسات المحلية: `.reports-check/settings-tabs/`، مستبعدة من Git لأنها تعرض البيئة المحلية المصرح بها.
