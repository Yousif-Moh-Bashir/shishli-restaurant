# تحسين الأكثر طلبًا

عنوان ورابط المنيو أوضح، ومنطقة خفيفة لاختيار الفرع، وبطاقات موحدة الصور والمسافات مع أسماء وأسعار وأزرار إضافة أكثر وضوحًا. يظهر عمودان على الهاتف، ولون الإضافة #d71920. التنسيق محصور في home-popular ولا يغير بطاقات المنيو الأخرى.

## BACKEND → FRONTEND COVERAGE

- المنتجات تظل من GET /menu بفلتر featured=1 والفرع الحالي؛ لا يُختلق ترتيب حسب المبيعات أو منتجات تجريبية.
- أسعار الفرع والتوفر والصور والإضافة للسلة والتحويل إلى خيارات المنتج المطلوبة بقيت على التكامل الحالي دون تغيير.
- العنوان والنص من featured_menu في CMS، مع المحتوى التسويقي الأصلي عند غياب النشر. حالات التحميل والخطأ وإعادة المحاولة والفراغ محفوظة.
- هذا تحسين عرض فقط؛ لا يُعرض المخزون أو إعدادات الفرع كحقول للعميل.

التحقق: نجح npm run build، ولم تُكتب بيانات إلى الخادم.
