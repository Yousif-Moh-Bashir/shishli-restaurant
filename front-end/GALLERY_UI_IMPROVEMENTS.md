# تحسين معرض الصور

بطاقات موحدة بصور واضحة وعناوين صغيرة، وسحب على الهاتف وتنقل بالأسهم مع مؤشر موضع الصورة. الضغط يفتح عرضًا مكبرًا داخل الموقع يدعم الأسهم ولوحة المفاتيح وEscape. حُفظت ألوان شيشلي والصور التسويقية الأصلية في الرئيسية عند غياب صور منشورة، دون استعمالها كصور منتجات للبيع.

المعرض المتحرك في الرئيسية ينتقل تلقائيًا كل ثانيتين ويعود للبداية عند النهاية. يتوقف أثناء تكبير الصورة أو تفاعل المؤشر/التركيز، وعند إخفاء الصفحة أو خروج المعرض من الشاشة، ويتوفر زر إيقاف مؤقت. تفضيل تقليل الحركة يوقف التشغيل الافتراضي. شبكة صفحة المعرض تبقى ثابتة.

صفحة المعرض تعرض شبكة الصور المنشورة من API بصورة مستقلة عن نشر صفحة CMS، مع حالات التحميل والخطأ والفراغ وترقيم صفحات الخادم. العرض المكبر يحافظ على أبعاد الصور المنشورة دون اقتصاصها.

## BACKEND → FRONTEND COVERAGE

- الخادم يقدم الصور النشطة المنشورة، العنوان والوصف والنص البديل والرابط والترتيب وترقيم الصفحات عبر GET /gallery.
- الواجهة الحالية كانت تعرض الصور والتنقل بين الصفحات، لكن الضغط في الرئيسية انتقل إلى صفحة أخرى ولم يوجد عرض مكبر.
- أُضيف العرض المكبر والتنقل ولوحة المفاتيح، ووُحد مكون العرض للرئيسية وصفحة المعرض، وأزيل اعتماد تحميل الصور على وجود صفحة CMS.
- حالة النشر والترتيب والرفع تُدار في الإدارة القائمة؛ لم تُكشف عمليات الكتابة في الموقع العام ولم يُغير الخادم أو عقد API.

التحقق: بناء الإنتاج وفحص Chrome عند 390 و768 و1440px، واختبار تكبير الصور والتنقل والإغلاق. اختبار غياب صفحة CMS مع صور منشورة يستخدم استجابة نقل معزولة، ولا يعدل البيانات الفعلية.
